# Séances L1 à L6

Les séances L1 à L6 complètent le projet personnel `mawid-web`. Chaque séance introduit les notions
de JavaScript nécessaires avant les notions React ou Node.js correspondantes, puis le code à écrire
dans le projet.

| Séance | Contenu | Dossier |
| --- | --- | --- |
| L1 | page d'un salon : composants, props, listes, état, données dérivées | [`L1`](L1/README.md) |
| L2 | échanges avec le serveur : promesses, `async` et `await`, `fetch`, `useEffect` | à paraître |
| L3 | formulaire de réservation et navigation entre les pages | à paraître |
| L4 | serveur Node.js avec Express | à paraître |
| L5 | persistance des données avec MongoDB | à paraître |
| L6 | comptes professionnels, agenda et mise en production | à paraître |

En début de séance, mettre ce dépôt à jour avec `git pull`. Chaque dossier `Ln` contient les
fichiers à copier dans le projet (`fournis/`), le code de chaque étape (`etapes/`), le support de
cours en PDF et la liste des commandes de la séance.
