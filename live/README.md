# Le cours live : L1 à L6

Jusqu'à fin décembre, chaque séance construit une partie de Mawid **dans votre propre projet**
`mawid-web`, en direct : l'enseignant tape le code, vous le tapez dans votre projet, un commit à
chaque étape. Avant chaque notion React, un rappel de JavaScript de cinq minutes.

| Séance | Ce qu'on construit | Dossier |
| --- | --- | --- |
| L1 | la page du salon : composants, props, listes, état, données dérivées | [`L1`](L1/README.md) |
| L2 | parler au serveur : promesses, `async` et `await`, `fetch`, `useEffect` | à venir |
| L3 | réserver, et donner une adresse à chaque page | à venir |
| L4 | Node.js et Express : la vraie API | à venir |
| L5 | MongoDB : les rendez-vous ne disparaissent plus | à venir |
| L6 | les comptes pro, l'agenda et la livraison | à venir |

Au début de chaque séance, dans ce dépôt : `git pull`. Chaque dossier `Ln` contient les fichiers à
copier dans votre projet (`fournis/`), le code de chaque étape pour rattraper (`etapes/`), les
diapos en PDF, et la liste des commandes au moment où elles servent.
