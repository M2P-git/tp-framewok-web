BUG.9 : deux onglets, deux boucles ?

Cette page s'appelle …. Horloge, mise à jour toutes les 50 ms : 0.00 s

Prêt

Cette page a été ouverte par une autre page avec window.open.

Consignes (15 minutes) : prédisez avant chaque expérience.

  1. Deux onglets indépendants. Ouvrez ce fichier dans deux onglets séparés (deux fois le même fichier, ou faites glisser le fichier dans un second onglet). Dans l'onglet 1, cliquez sur « Calcul bloquant ». Que fait l'horloge de l'onglet 2 ? Et celle de l'onglet 1 ?
  2. Un onglet ouvert par un autre. Dans l'onglet 1, cliquez sur « Ouvrir une page liée » : un nouvel onglet s'ouvre. Cliquez de nouveau sur « Calcul bloquant » dans l'onglet 1. Que fait l'horloge du nouvel onglet ?
  3. Qu'en concluez-vous sur le nombre de boucles d'événements ? Dessinez, pour chaque cas, qui partage quoi (la pile, les files, le fil).
  4. Pour un vrai calcul lourd, comment éviter de geler la page ? (Indice : le cours cite trois solutions, dont une qui utilise un autre fil.)
