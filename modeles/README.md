# La boîte à outils du freelance

Des modèles à copier dans le dossier `docs/` de votre dépôt, puis à remplir. Ce sont les
documents qu'un développeur indépendant produit réellement pour un client : on les remplit
pour Mawid pendant le module, et on les réutilise ensuite pour ses propres missions.

| Modèle | Quand | À quoi il sert |
| --- | --- | --- |
| [`questions-client.md`](questions-client.md) | avant la réunion de lancement (S1) | ne rien oublier de demander |
| [`fiche-cadrage.md`](fiche-cadrage.md) | après la réunion (S1) | une page qui dit ce qu'on construit, pour qui, et ce qu'on ne construit pas |
| [`user-stories.md`](user-stories.md) | S1, puis tout le module | le backlog : les besoins, triés, avec leurs critères d'acceptation |
| [`proposition-milestones.md`](proposition-milestones.md) | S1 (projet d'équipe) | la proposition au client : le MVP, les jalons, les dates, le prix |
| [`pv-recette.md`](pv-recette.md) | à chaque jalon (S4, S8, S12) | le procès-verbal de recette : ce que le client a vérifié et accepté |
| [`journal-ia.md`](journal-ia.md) | tout le module | ce que vous avez demandé à l'IA, ce que vous avez gardé, et pourquoi |
| [`readme-portfolio.md`](readme-portfolio.md) | S4, puis S12 | le README de votre dépôt, écrit comme une étude de cas de portfolio |
| [`AGENTS.md`](AGENTS.md) | dès S2 | les règles du projet, que les assistants IA lisent avant d'écrire du code |
